# すすみ 動作確認チェックリスト（Windows）

別のWindowsパソコンで `susumi_windows.exe` を動かして、次の7項目を順に確認してください。
結果は、各項目の「結果」に書き込んでください。

警告の画面とファイアウォールの画面が出たときは、スマートフォンなどで画面の写真を撮ってください。
写真は、利用者向けの手順書を作るときに使います。

## 準備

- `susumi_windows.exe` を、確認に使うパソコンのデスクトップなどに置く。
- 同じネットワークにつながった、別のパソコンをもう1台用意する（項目6で使う）。

## 確認項目

### 1. ダブルクリックで起動する

- `susumi_windows.exe` をダブルクリックする。
- 青い画面（SmartScreen）が出たら、「詳細情報」を押してから「実行」を押す。
- 黒いウィンドウが開き、「すすみ（版 0.1.0）が起動しました」と表示されれば合格。
- 結果：
- 写真：SmartScreen の画面（出た場合）

### 2. ファイアウォールの確認

- Windows セキュリティの画面が出たら、「プライベートネットワーク」にチェックを入れて「アクセスを許可する」を押す。
- 管理者のパスワードや、管理者の確認を求められたかどうかを記録する。
- 結果：
- 管理者の確認を求められた（はい・いいえ）：
- 写真：ファイアウォールの画面（出た場合）

### 3. ブラウザで画面が開く

- 起動のあと、自動でブラウザが開き、画面が表示されれば合格。

- ブラウザで `http://localhost:4000/_check` を開く。
- 「+1」を押すたびに、「回数: N」の数が1つずつ増えれば合格。
- 結果：

### 5. 閉じて再び起動しても、数が残る

- 黒いウィンドウを閉じる（すすみが停止する）。
- 閉じた直後に、ブラウザで `http://localhost:4000` を開く。つながらなければ（開けなければ）停止している。つながってしまう場合は不合格として記録する。
- もう一度 `susumi_windows.exe` をダブルクリックして起動する。
- `/_check` を開き、閉じる前の数が残っていれば合格。

## 同じ版で作り直した実行ファイルを試すとき

すすみは、初回の起動時に、中身を次のフォルダに展開して使います。
同じ版番号のまま実行ファイルを作り直して試すときは、古い展開が使われないよう、先にこのフォルダを削除してください。

- Windows：`%LOCALAPPDATA%\.burrito\susumi_erts-17.1.1_0.1.0`（推測。Burrito の仕様から推測したもので、Windows では未確認。見つからなければ、`susumi_windows.exe maintenance directory` で場所を確認できる）
- macOS：`~/Library/Application Support/.burrito/susumi_erts-17.1.1_0.1.0`（確認済み）

## macOS で確認する場合（開発者が端末から確認できなかった項目）

開発者は、ターミナルからの起動、`/_check` の表示、再起動後に数が残ること、ポート使用中の案内までを確認済みです。次の項目は、実機で確認してください。

1. Finder で `susumi_macos_arm`（Intel Mac は `susumi_macos_intel`）をダブルクリックして起動する。開発元が未確認の旨の警告が出たら、「システム設定 → プライバシーとセキュリティ」から許可する。
2. 既定のデータフォルダ `~/Library/Application Support/Susumi/` に `susumi.db` ができる。
3. macOS のファイアウォールが「着信接続を許可しますか」と尋ねたら「許可」を押す。そのあと、別の端末から `http://<このMacのIPアドレス>:4000/_check` を開いて表示される。
4. 2つのブラウザで `/_check` を開き、片方で「+1」を押すと、もう片方の数が画面を更新しなくても変わる。

## データの場所

- データ（`susumi.db`）、設定（`config.json`）、バックアップ（`backups`）は、`%LOCALAPPDATA%\Susumi\` に作られます。
- 確認が終わったら、このフォルダを削除しても構いません。

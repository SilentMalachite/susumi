# すすみ 動作確認チェックリスト（Windows）

別のWindowsパソコンで `susumi_windows.exe` を動かして、次の7項目を順に確認してください。
結果は、各項目の「結果」に書き込んでください。

警告の画面とファイアウォールの画面が出たときは、スマートフォンなどで画面の写真を撮ってください。
写真は、利用者向けの手順書を作るときに使います。

## 準備

- `susumi_windows.exe` を、確認に使うパソコンのデスクトップなどに置く。
- 同じネットワークにつながった、別のパソコンをもう1台用意する（項目6で使う）。

## 確認項目

### 1. ダブルクリックで起動する

- `susumi_windows.exe` をダブルクリックする。
- 青い画面（SmartScreen）が出たら、「詳細情報」を押してから「実行」を押す。
- 黒いウィンドウが開き、「すすみが起動しました」と表示されれば合格。
- 結果：
- 写真：SmartScreen の画面（出た場合）

### 2. ファイアウォールの確認

- Windows セキュリティの画面が出たら、「プライベートネットワーク」にチェックを入れて「アクセスを許可する」を押す。
- 管理者のパスワードや、管理者の確認を求められたかどうかを記録する。
- 結果：
- 管理者の確認を求められた（はい・いいえ）：
- 写真：ファイアウォールの画面（出た場合）

## データの場所

- データ（`susumi.db`）、設定（`config.json`）、バックアップ（`backups`）は、`%LOCALAPPDATA%\Susumi\` に作られます。
- 確認が終わったら、このフォルダを削除しても構いません。
